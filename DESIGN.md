# Freeform design

The toolbox opens directly into a working task. No account gate or separate landing page. Six clearly named tasks expose the right input: a conversation, document upload, image prompt, audio upload, reading passage, or portrait.

- Palette: paper `#ffffff`, lavender mist `#f5f4fa`, ink `#252333`, iris `#6150d6`, lemon `#f5dc68`, mint `#dff0e8`.
- Type: self-hosted Bricolage Grotesque headings and DM Sans controls and reading text.
- Character: one yellow star gives the otherwise quiet workspace a playful identity.
- Layout: welcome and task selector above a composer; a compact model panel beside it. On narrow screens the model panel moves below the composer. Phone screens show all six task buttons in two columns.
- Progressive detail: simple pace choices first, full model names, download sizes, memory guidance, licenses, and a model picker available nearby.
- Feedback: explicit download consent, real progress, a visible Stop action, recoverable errors, and downloadable results. Relative pace labels are not benchmark scores or guarantees that a model fits.
- Accessibility: native buttons, labels, dialogs and media controls; visible focus, a skip link, status announcements, and reduced-motion support.

The approved original design is preserved in `design/mockup.html` with its screenshots. Those files are historical design references. The Vite application in `src/` provides real local inference. See `docs/VALIDATION.md` for tested flows and limitations.
